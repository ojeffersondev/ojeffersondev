# Fontes e adaptações dos ícones — 19/11/2026

Todos os SVGs são locais. A moldura de 48×48 px foi criada para combinar com o estilo do Skill Icons. As marcas pertencem aos respectivos titulares; confira suas regras de marca antes de reutilizá-las fora do perfil.

A identidade Docker de 19/11/2026 foi confirmada no [anúncio oficial](https://www.docker.com/blog/meet-the-new-docker-built-to-run-on-trust/). As fontes secundárias não equivalem a uma validação independente de todas as diretrizes de marca atuais. Os SVGs foram renderizados localmente; o layout total não foi testado em um repositório publicado. O cabeçalho animado e os badges sociais continuam sendo carregados externamente.
